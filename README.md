# Spill Toko — Extension

Proyek pribadi: extension browser (Chrome, Manifest V3) untuk riset dan analisis data produk e-commerce.
Terhubung ke layanan server milik pemilik untuk akun, langganan, dan analisis berbasis AI.

## Gambaran umum
- Menampilkan ringkasan data produk dan toko langsung di halaman yang sedang dibuka.
- Menyimpan koleksi data secara lokal di browser pengguna.
- Fitur dikunci oleh login akun dan langganan aktif.

## Status
Dalam pengembangan, hanya untuk penggunaan internal pemilik.
